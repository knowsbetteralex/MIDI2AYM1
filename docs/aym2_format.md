# AYM2 v1 — нормативный формат ПК-кодека

Версия кодека: **1**, дата спецификации: **2026-11-21**. Реализует обязательный
lossless-этап [ТЗ](aym2_compression_spec.md). Процедурные инструменты и фразы
не входят в v1. Поддержка в Z80-плеере и измерения IM2 — отдельный этап;
до него совместимым форматом SpaceCan по умолчанию остаётся AYM1.

Все числа little-endian, все смещения абсолютные от начала файла.
Размер всего блока не больше 65535 байт; загрузчик также обязан проверить,
что адрес загрузки + размер блока не пересекает #10000.

## Заголовок: 24 байта

| Смещение | Байт | Значение |
|---|---:|---|
| 0 | 4 | ASCII `AYM2` |
| 4 | 1 | Версия: 1 |
| 5 | 1 | FPS: 50 |
| 6 | 1 | Флаги: бит 0 loop, остальные 0 |
| 7 | 1 | Число записей словаря: 0..96 |
| 8 | 2 | Полный размер блока |
| 10 | 2 | Смещение loop; 0 при выключенном loop |
| 12 | 4 | AY clock Hz, ненулевой |
| 16 | 2 | Конец потока (исключительно), он же начало таблицы словаря |
| 18 | 2 | Начало тел словаря = конец потока + 2 × число записей |
| 20 | 4 | Reserved: 0 |

Поток начинается строго с +24. END — последний байт потока. За ним таблица
16-битных указателей, затем тела словаря. Указатели задают начала полных
FRAME-команд, по возрастанию, плотно без пропусков, пересечений или хвостовых
байтов. Первый указатель равен началу тел, последнее тело заканчивается
ровно на границе файла. При пустом словаре обе границы равны размеру файла.

## Карта команд

Каждая FRAME, короткая команда или TOKEN потребляет ровно один слот 20 мс.
Все указанные записи выполняются по возрастанию номера регистра, даже если
значение уже совпадает с зеркалом. Это включает повторные записи R13.

| Opcode | Данные | Действие |
|---|---|---|
| `00` | — | END; остановка или loop без дополнительного временного слота |
| `01..7F` | — | WAIT N: N слотов без записей |
| `80` | mask16, значения | Полный FRAME, как в AYM1 |
| `81..8E` | value | Один регистр R0..R13 соответственно |
| `8F..91` | — | MUTE A/B/C: запись 0 в R8/R9/R10 |
| `92..94` | low, high, volume | R0,R1,R8 / R2,R3,R9 / R4,R5,R10 |
| `95..97` | low, high | R0,R1 / R2,R3 / R4,R5 |
| `98..9A` | noise, mixer, volume | R6,R7,R8 / R6,R7,R9 / R6,R7,R10 |
| `9B` | a,b,c | R8,R9,R10 |
| `9C` | mixer,a,b,c | R7,R8,R9,R10 |
| `9D..9F` | — | Reserved, отвергать |
| `A0..FF` | — | TOKEN 0..95, индекс = opcode − A0 |

Словарь содержит только полные FRAME `80 mask16 values`, без токенов,
WAIT, END или коротких операций. Вложенность и рекурсия невозможны.
Индекс TOKEN должен быть меньше числа записей в заголовке. Режим сжатия
не нужен декодеру: все допустимые примитивы разрешены в любом AYM2 v1.

## Валидация и время

Маска FRAME использует только биты 0..13; значения идут по возрастанию
регистра. Первая развёрнутая команда должна инициализировать как минимум
R0..R5, R7..R10 (`mask & 07BF = 07BF`); R6 необязателен. Начальное зеркало:
R7=3F, прочие регистры 0. Пустая FRAME допустима и отличается от WAIT
только наличием FRAME в трассе команд.

R1/3/5/13: 0..15; R6: 0..31; R7: 0..63 (GPIO-биты сброшены);
R8/9/10: 0..31 (бит hardware envelope сохранён); прочие: 0..255.
WAIT до начальной FRAME запрещён. Обязателен END, поток непустой.
Loop указывает только на начало временной команды основного потока,
включая WAIT или TOKEN, но не END, данные команды или словарь.
На END следующая команда loop исполняется в том же AY_TICK. При loop
в середину WAIT он повторяется целиком. Состояние AY на loop не сбрасывается.

Декодирование не требует поиска: один слот выполняет не более одного FRAME
с 14 записями; TOKEN добавляет одно чтение указателя. WAIT/END не создают
лишних кадров. ПК-декодер ограничивает длительность прохода 1 000 000 слотов.

## Выбор кодировки

`none`: полные FRAME; `short`: самые короткие фиксированные операции;
`dictionary`: короткие операции плюс до 96 прибыльных точных FRAME.
Для команды с N появлениями, полной длиной L и длиной короткой кодировки S
чистая выгода словаря равна `N × (S − 1) − L − 2`. Берутся только положительные
выгоды, по убыванию; при равенстве — лексикографически по FRAME. Такая оценка
учитывает конкуренцию коротких команд и словаря. Вывод детерминирован.

`--format auto` выбирает меньший полный блок, включая все заголовки и таблицы;
при равенстве выбирает AYM1. Явный `aym2` сохраняет выбранный формат, даже
если файл больше, и сообщает об этом в отчёте. Превышение 65535 байт
отвергается; auto может выбрать другой помещающийся формат. Общий бюджет
RAM игры и T-states не выводятся из размера файла: они требуют проверки
после интеграции Z80-декодера.
